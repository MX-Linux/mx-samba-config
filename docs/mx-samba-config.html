MX Samba Config Help

MX Samba Config is the MX Linux tool for managing Samba users and user shares from a Qt interface.

Main Tasks

  • Enable or disable automatic Samba startup.
  • Start or stop the Samba service.
  • Add or remove Samba users.
  • Create, edit, and remove shared folders.

Users

Use the user controls to add Samba passwords for existing system users or remove Samba access when it is no longer needed.

Most installations also enable the [homes] section in /etc/samba/smb.conf. It lets each Samba user open their own home folder over the network as \\hostname\username. Only that user can open it, with their Samba password; it is read-only by default and hidden from the list of shares clients browse. It is not a usershare, so it does not appear in the share list. When it is enabled, the Users tab shows a note. To turn it off, remove or comment out the [homes] section in /etc/samba/smb.conf as root and restart Samba.

Shares

The share list shows folders exported through Samba usershares. Add a new share for a folder you own, or edit an existing share to change its folder, comment, guest access, or access rights. An existing share keeps its name; to use a different name, remove it and create a new share.

Changes to a share take effect for new connections without restarting Samba. Clients that are already connected keep the access they had until they reconnect, so removing write access, for example, may not stop a connected client from writing right away. Restart Samba with the button below the share list to apply a change to everyone immediately; this disconnects all clients.

Service Controls

The Samba buttons at the bottom of the main window let you control whether the service starts automatically and whether it is currently running.

Notes

  • Shares typically need to point to folders owned by the user creating them.
  • Remote systems may need to reconnect after share or permission changes.
  • Package documentation, including the license and changelog, is installed under /usr/share/doc/mx-samba-config/.
